Build the shortcut

{{ api_url }}

In the Shortcuts app on your iPhone, tap + and name it I did a chore. Then add these actions:

  1. Ask for Input: type Text, prompt Which chore did you complete?
  2. Get Contents of URL: {{ api_url }}. Tap the arrow to show more, then set Method POST, add a header Authorization with the value Bearer, a space, and your key, and set Request Body to JSON with a Text field text set to Provided Input.
  3. Get Dictionary Value: get Value for speech in Contents of URL.
  4. Show Result with Dictionary Value. Siri reads it aloud, and it also appears on Apple Watch and CarPlay.

Run it once by tapping it and allow it to connect. Turn on Show on Apple Watch in the shortcut’s details if you’d like it there.

Optional extras

Duplicate the shortcut, delete Ask for Input, and set text to fixed words instead:

  • What chores do I have left today: text what's left. Siri reads your remaining daily chores, then anything due today or overdue.
  • Undo my last chore: text undo (works for an hour)
  • What's my chore score: text score
  • Add a chore: keep Ask for Input, then send add a task, a space, and the input as text. It creates a one-off task owned by you.

Siri understands nicknames from each task's Also called field. When several dates or laundry loads are ready for the same task, it chooses the oldest ready one and says which date it used. UI undo is available under Completed for correcting several tasks.

Optional: choose when two task names match

The API reply includes an options list when names are ambiguous. You can use If → Choose from List in Shortcuts, then send the chosen full name to the same API. Keep the spoken fallback as well. This optional interaction still needs testing on your particular iPhone, Watch or CarPlay setup.
